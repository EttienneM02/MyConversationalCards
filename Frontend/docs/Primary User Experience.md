Primary User Experience
The core experience should be:

User opens the website.

User chooses the type of conversation they want.

User optionally chooses a relationship stage or depth.

The generator presents a conversation prompt.

User can:

Generate another prompt

Save the prompt

Mark it as a favorite

Reveal a deeper follow-up question

Share the prompt

The user can continue generating prompts.
Example
Category: Romance

"What's something small a partner can do that instantly makes you feel loved?"

Actions:

Another Piece

Go Deeper

Save

Share

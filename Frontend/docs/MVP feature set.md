20. Accessibility
The application should:

Support keyboard navigation.

Use semantic HTML.

Provide visible focus states.

Maintain sufficient color contrast.

Use accessible button labels.

Avoid relying solely on color to communicate state.

Support mobile screen readers.

Respect reduced-motion preferences.

21. Content Guidelines
Prompts should be:

Open-ended

Conversational

Non-judgmental

Specific enough to answer

Interesting without being intrusive

Appropriate for the selected relationship stage

Avoid:

Manipulative questions

Pressure to disclose trauma

Assumptions about marriage or children

Gender stereotypes

Judgmental wording

Questions designed to provoke jealousy

Explicit sexual content by default

Questions that frame one answer as morally superior

22. Tone of Voice
The brand should sound:

Warm

Curious

Romantic

Playful

Human

Encouraging

Avoid:

Corporate language

Clinical language

Excessive relationship advice

Clichéd motivational language

Brand principle
Don't tell couples what to talk about. Give them a reason to start talking.

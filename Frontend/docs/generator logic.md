The visual identity should communicate:

Modern romance + conversation + warmth

Rounded cards

Generous whitespace

Elegant typography

Subtle animations

Friendly micro-interactions

Mobile-first layout

Avoid making the site look like:

A dating app

A social network

A therapy application

A personality test

A generic random-question website
